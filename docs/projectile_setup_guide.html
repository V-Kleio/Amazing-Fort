Projectile (Plushie) Setup

Amazing Fort · randomized plushie sprite + reticle
Working now with no editor step: the reticle icon is scaled down (no more giant sprite), the dotted arc is gone, the ball aims at the Kid, the ball settles correctly, and win/lose result screens work (Continue advances or returns to menu). Until you assign plushies, the ball keeps using its default sprite.

1Import the 5 plushie sprites

  1. Drop the 5 plushie PNGs into e.g. res://assets/visual/projectile/ (any names).
  2. They can be different native sizes — the code scales each to a consistent on-screen size.

2Assign them on the Attacker

  1. Open res://entities/attacker/attacker.tscn, select the Attacker root.
  2. Inspector → Projectile Sprites → set the array size to 5 and drop each plushie texture in.
  3. Each round it picks one at random and uses it for both the reticle icon and the fired ball (they always match).

The reticle's Arrow art should point down at rotation 0 (it's rotated to aim). If you want the red ring back, add a Circle Sprite2D behind ProjectileIcon — it's optional and not required by the code.

Verify

  1. Reticle shows a small plushie icon; no dotted arc; icon + fired ball are the same plushie and vary across rounds.
  2. Ball flies at the Kid, bounces, and comes to rest → round resolves (no mid-air freeze, no endless bounce).
  3. Win → result screen → Continue → next round. Lose (Kid takes 3 hits) → "Defeated" → Continue → main menu.
