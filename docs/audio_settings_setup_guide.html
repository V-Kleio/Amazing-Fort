Audio & Settings — Setup Guide

Amazing Fort · global music/SFX + mobile settings menu (editor steps)

The audio + settings logic is code-complete (AudioManager, Settings overlay, persistence, pause wiring). What remains is done in the Godot editor: registering the autoload and building the settings scene + pause button. Do the steps in order.

Steps
  1. Register the AudioManager autoload do first
  2. Create the audio bus layout (Master / Music / SFX)
  3. Build the Settings scene
  4. Wire the main-menu Settings button
  5. Add the in-game pause button
  6. Add audio files & assign music (optional, when you have assets)
  7. Run & verify
Everything runs silently but error-free until you add audio files — the system is built now; sound arrives when you drop in .ogg/.wav assets (Step 6).

1Register the AudioManager autoload

  1. Project → Project Settings… → Globals / Autoload tab.
  2. Path = res://autoloads/audio_manager.gd; Node Name = AudioManager.
  3. Add. It appears at the bottom of the list — which is after SaveManager, exactly what we need (AudioManager reads saved volumes on ready). Leave it there.
The autoload list should read: GameEvents, GameManager, SaveManager, SceneManager, PlayerInventory, AudioManager.

2Create the audio bus layout

This gives you separate Music and SFX volume control and makes the buses selectable in the editor. (AudioManager also creates them at runtime, so this step is recommended but not strictly required.)

  1. Open the Audio tab in the bottom panel. You'll see one Master bus.
  2. Click Add Bus twice → two new buses appear. Double-click each name and rename to Music and SFX.
  3. At the bottom of the Music bus strip there's a send dropdown — make sure it's set to Master (default). Same for SFX.
  4. Top-right of the Audio panel → the layout menu → Save As… → save as res://default_bus_layout.tres (Godot loads this automatically).

3Build the Settings scene

Create res://scenes/ui/settings.tscn.

  1. Scene → New Scene → Other Node → CanvasLayer as root; rename to Settings.
  2. Select Settings → set Layer = 90 and Process → Mode = Always.
  3. Build this tree (names must match exactly — the script reads these paths):
Settings (CanvasLayer) <- attach settings.gd; Layer 90; Process Mode = Always └ Root (Control) full rect (Anchors Preset = Full Rect) ├ Background (ColorRect) full rect; Color rgba(0,0,0,0.6) └ Panel (PanelContainer) centered └ VBox (VBoxContainer) ├ TitleLabel (Label) text "Settings" ├ MasterRow (HBoxContainer) → Label "Master" + MasterSlider (HSlider) ├ MusicRow (HBoxContainer) → Label "Music" + MusicSlider (HSlider) ├ SfxRow (HBoxContainer) → Label "SFX" + SfxSlider (HSlider) ├ MuteRow (HBoxContainer) → Label "Mute All" + MuteToggle (CheckButton) ├ ResetTutorialButton (Button) text "Replay Tutorial" └ CloseButton (Button) text "Back"
NodeKey properties
each HSliderMin Value 0, Max Value 1, Step 0.01; Layout → Container Sizing → Horizontal = Fill + Expand (so it fills the row)
each row Labelgive a fixed Custom Minimum Size width (e.g. x=180) so sliders align
Panelanchor centered; give the VBox some min width (e.g. 560) and a Theme Override → Constants → Separation ~14
Backgroundsemi-transparent so a paused game shows behind it in-game
Select the Settings root → Attach Script → Load → res://scenes/ui/settings.gd. Save the scene.
You don't wire any button signals in the editor — settings.gd connects the sliders, toggle, and buttons in code. Just match the node names/paths above.

4Wire the main-menu Settings button

  1. Open res://scenes/ui/main_menu.tscn, select the MainMenu root.
  2. Inspector → Settings Scene = scenes/ui/settings.tscn.
  3. (Optional) Menu Music = a music AudioStream (once you have one).
  4. Save. The existing Settings button already opens it (no pause needed on the menu).

5Add the in-game pause button

Open res://scenes/level_controller.tscn (root Level). Add a HUD with a pause button:

Level (Node2D) ├ PhaseContainer (existing) ├ Arena / spawns (existing / runtime) └ HUD (CanvasLayer) Layer = 50 └ PauseButton (Button) text "II" (or "Pause"); anchored top-right corner
  1. Add a CanvasLayer named HUD under Level; set Layer = 50.
  2. Add a Button named PauseButton under HUD; anchor it to a top corner, give it a small size. path must be HUD/PauseButton
  3. Select the Level root → Inspector → Settings Scene = scenes/ui/settings.tscn; (optional) Gameplay Music = a track.
  4. Save.
The script auto-connects HUD/PauseButton if present (it's optional — no crash if you skip it). Pressing it pauses the game (get_tree().paused) and opens Settings on top; Back unpauses. Audio keeps playing through the pause because AudioManager runs with Process Mode = Always.

6Add audio files & assign music (optional, later)

  1. Put audio under e.g. res://assets/audio/music/ and res://assets/audio/sfx/. For looping music, select the imported track → Import dock → enable Loop → Reimport (the code also loops non-looping tracks as a fallback).
  2. Assign Menu Music (on MainMenu) and Gameplay Music (on Level).
  3. For SFX, call AudioManager.play_sfx(my_stream) from any script. To make the Kid's hurt sound obey the SFX slider, open entities/kid/kid.tscn, select its AudioStreamPlayer2D, set Bus = SFX, and assign hurt_sound.

7Run & verify

  1. F5 → main menu → Settings: the panel fades in; sliders show saved values.
  2. Drag Music/SFX/Master (audible once music/SFX exist). Toggle Mute All → silence; untoggle → restores.
  3. Back, reopen → values persisted. Relaunch the game → still persisted (stored in user://save_data.json).
  4. Replay Tutorial → return to menu → Start → the tutorial shows again.
  5. Start a run → press the pause button → the game freezes and Settings opens on top; Back resumes.
  6. (With music assigned) menu → Start crossfades to the gameplay track; game over crossfades back to the menu track.
SFX smoke test: temporarily add AudioManager.play_sfx(preload("res://assets/audio/sfx/<file>.wav")) to any button handler → it plays on the SFX bus and obeys the SFX slider & mute.
