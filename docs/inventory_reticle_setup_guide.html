1Collapsible inventory bar

Open res://scenes/phases/building_phase.tscn. Wrap the existing bar in a plain tray Control (so sliding it isn't fought by slot re-sorts) and add a briefcase toggle. Target tree:

CanvasLayer/Control ├ InventoryTray (Control) bottom-anchored; holds the bar + optional board │ ├ BarBackground (TextureRect) the wooden plank (optional) │ └ InventoryBar (HBoxContainer) ← MOVE the existing bar under the tray (keep its name/settings) ├ InventoryToggle (TextureButton) briefcase icon, bottom-right, always visible ├ PlayButton (TextureButton) (unchanged) └ DeleteButton (TextureButton) (unchanged)
  1. Add a Control named InventoryTray under Control; anchor it across the bottom (Anchors Preset Bottom Wide) with enough height for the bar (~200–260 px).
  2. Reparent the existing InventoryBar (HBoxContainer) to be a child of InventoryTray (drag it in the Scene dock). Keep its name InventoryBar and its settings (separation 16, alignment center).
  3. (Optional) Add BarBackground (TextureRect) as the tray's first child, behind the bar; assign the wooden-plank art.
  4. Add InventoryToggle (TextureButton) as a child of Control, anchored bottom-right; assign the green briefcase icon (texture_normal).
  5. Save. Node names must match exactly — the script resolves them by path and falls back gracefully if absent.
The bar starts expanded and slides in on build start; the briefcase collapses/expands it. Slots whose count is 0 hide automatically (no setup). If InventoryTray is missing, the code still finds the old flat InventoryBar and just skips the collapse animation.

2Attack reticle

Open res://entities/attacker/attacker.tscn. Replace the placeholder Kid Sprite2D with reticle parts (all Sprite2D in this Node2D scene). Target tree:

Attacker (Node2D) attacker.gd ├ Circle (Sprite2D) the red ring, upright ├ ProjectileIcon (Sprite2D) sits inside the ring; texture set at runtime ├ Arrow (Sprite2D) the arrowhead; points DOWN at rotation 0 └ Marker2D muzzle / ball spawn — at the ring center
  1. Delete the old placeholder Sprite2D (bocil). Add Circle, ProjectileIcon, Arrow (Sprite2D) — names exact.
  2. Assign the red-circle art to Circle and the arrow art to Arrow. The arrow art must point straight down at rotation 0 (the script rotates it to aim at the Kid).
  3. Position Arrow so it rotates around the ring's center — set the Arrow's node origin at the ring center (the arrowhead extends outward). Center Circle and ProjectileIcon on the node origin too.
  4. Move Marker2D to the ring center (this is where the ball spawns). Leave ProjectileIcon texture empty — it's filled from the ball's sprite at runtime.
  5. Save.
Aiming changed: the ball now launches toward the Kid (with a small Aim Spread Deg, default 8°) instead of a fixed horizontal shot. Tune Aim Spread Deg on the Attacker root if you want more/less scatter.
